# Book API — APIView

Book API is a RESTFULL API built with Django REST Framework using APIView.

The project focuses on managing book data and demonstrates how REST API functionality can be implemented using APIView.

Purpose

The purpose of this project is to practice an alternative approach to REST API development using Django REST Framework's APIView.

Features

- Book Management
- RESTFULL API
- CRUD operations
- APIView
- Serializers
- Database integration
- API endpoints

Architecture

The API is implemented using Django REST Framework's `api_view`.

This provides direct control over the API request and response logic.

Technologies

- Python
- Django
- Django REST Framework
- APIView
- REST API
- Database
